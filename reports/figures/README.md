# reports/figures/

Chart PNGs generated by `src/adip/reporting/charts.py`. Regenerated every
pipeline run, but only *committed* by `pipeline.yml` if a chart's byte
content actually differs from what's already in git (see
`src/adip/change_detection.py`). Filenames are stable
(`current_temperature_by_city.png`, `forecast_error_by_horizon.png`,
`anomaly_timeline.png`, `temperature_trend_<city_id>.png`) so the README
and reports can link to them predictably.
